# Security Policy

## Reporting a vulnerability

If you discover a security issue, please report it responsibly.

Preferred reporting methods:
- Open a private security advisory on GitHub for this repository.
- If you cannot use GitHub security advisories, open an issue marked as confidential.

## Supported versions

This repository is actively maintained, and security fixes are applied as needed.

## Third-party dependencies

This project uses dependencies managed by npm and Docker images. Keep dependencies up to date and review security alerts in GitHub.
